There is no submit action and this page sends no data. FormRewind observes supported local field changes through its packaged content script.

Reviewer steps

  1. Type sample text.For example, enter “Reviewer Draft One” in Project lead.
  2. Wait about two seconds.Open FormRewind and confirm History on.
  3. Edit the value.Change it to “Reviewer Draft Two” and wait again.
  4. View history.Open FormRewind, choose View history, and select the earlier version.
  5. Inspect and restore.Review Previous version / Selected version, then restore one field or matching fields.
  6. Pause and resume.Use the popup to confirm changes are ignored while paused and resume afterward.

Expected limitation: a field may remain unchanged if FormRewind cannot match it with enough confidence.
